# Zoo Test Site (intentionally inaccessible)

**Live:** https://zoo-test-site.vercel.app

⚠️ **This site is broken on purpose.** It's a test fixture for
[AccessBridge](https://accessbridge.app), my accessibility compliance tool built around the
European Accessibility Act (EAA) and WCAG 2.2.

It contains common real-world accessibility failures (missing alternative text, low contrast,
unlabeled form fields, poor heading structure, keyboard traps and more) so the scanner and the
fix workflow can be tested and demonstrated against known problems.

Its accessible counterpart is [wildlife-test-site](https://github.com/kevinmccalley/wildlife-test-site).

## Stack
Plain HTML, CSS and JavaScript · Vercel

Please don't use this site as an example of how to build things. 🙂
